# 🏦 存哪儿 · 存款利率与国债

> 钱存哪儿利息最高？国有大行挂牌利率、大额存单、储蓄国债、中小银行参考一页对比，附利息计算器和 15 年调息记录

**🌐 在线访问：[https://climb0516.github.io/savings-rates/](https://climb0516.github.io/savings-rates/)**

---

## 功能

- **顶部要点**：大行 3 年定期（及「已多少天未调」）、大额存单 3 年、储蓄国债 3 / 5 年、**下期国债倒计时**
- **利息计算器**：输入金额、选 1 / 2 / 3 / 5 年，对比大行定期、大额存单（不足起存金额时置灰）、储蓄国债（只有 3 / 5 年）、股份行 / 城商行参考，最高的高亮并算出比大行多拿多少
- **利率对比表**：活期到 5 年各渠道利率，每行最高值高亮
- **调息记录**：中国银行历次挂牌利率表（2010 年至今），阶梯折线图（3 年 / 1 年定期 + 储蓄国债 3 年），悬停看每次的利率；下方卡片列出每次调整幅度
- **调息提醒**：中行发布新利率表后 30 天内，页面顶部高亮提示
- **储蓄国债**：下期开售倒计时（已有公告用公告日期，否则按 3–11 月每月 10 日推算并标「预计」），历次发行一览（品种、期数、3 / 5 年利率、公告链接）
- **最新动态**：国债、存款利率、大额存单新闻，可按主题筛选
- 右侧：LPR、大行中行 / 农行交叉核对、中小银行参考区间、来源状态
- 深色 / 浅色主题，手机适配；输入的金额只保存在本机浏览器

数据仅供参考，不构成理财建议。

## 技术架构

```
GitHub Actions（触发条件：定时 每天北京时间 09:05、17:05 / push 改动 scraper.py、others.json、scrape.yml / 手动）
  ↓ python scraper.py（Python 3.12，只用标准库）
  ↓ 读上一份 data.json 作为缓存（历史利率表、已解析的国债公告不重复请求）
  ↓ 抓取 5 个自动来源：中行利率表 / 农行利率页 / 中行国债+大额存单公告 / 外汇交易中心 LPR / Google News RSS
  ↓ 合并人工维护的 others.json（股份行、城商行参考）
  ↓ 写入 data.json，git commit + push（updated 每次都变 = 心跳）
       ↓
GitHub Pages（index.html）
  ↓ fetch('data.json', { cache: 'no-cache' })，计算器、折线图、倒计时都在前端算
  ↓ 首页：要点卡片 / 利息计算器 / 利率对比表 / 调息记录 / 储蓄国债 / 最新动态
  ↓ 详情抽屉（#/item/类型/id）+ 列表页（#/list/news、history、bonds）
```

| Google News | RSS 搜索 | 3 个关键词各取近 30 天，去重后最多 40 条 | 关键词见 `news()`：「储蓄国债」「存款利率 下调 OR 上调 银行」「大额存单 利率」 |
| 股份行 / 城商行参考 | **人工维护** `others.json` | 当前 2 组（股份制银行、城商行 / 农商行） | 来自第三方文章整理，scraper 原样并入 `data.json.others` |

**增删来源**：每个自动来源是 `scraper.py` 里的一个函数，在 `main()` 中用 `run("显示名", 函数, 参数)` 调用；新增来源就写一个函数并在 `main()` 里加一行 `run(...)`，结果放进 `data` 字典；删除时去掉对应 `run(...)` 和字段。新闻关键词改 `news()` 里的元组，中行公告翻页数改 `boc_notices(pages=4)`。`run()` 会自动往 `sources` 里记录成功 / 失败，失败时沿用上一份数据。

**限制**：
- 工行、建行、邮储页面是 JS 渲染，招行拦截爬虫，未接入；六大行挂牌利率一致，用中行代表、农行核对
- 中行国债公告没有发行额度，页面不显示额度
- 股份行 / 城商行没有可靠的结构化来源，活动价通常有新客 / 新资金 / 起存金额条件，只作参考，需要定期手动更新 `others.json`（改完 push 会自动重新抓取）

## 数据处理规则

**挂牌利率解析**（`parse_deposit()`）
- 先用 `text_of()` 去掉 script / style / 标签，空白压成单个空格
- `DEPOSIT_RE` 按顺序匹配「整存整取 三个月 / 半年（或六个月） / 一年 / 二年 / 三年 / 五年」，`DEMAND_RE` 匹配「活期（存款）」
- 输出固定 7 个期限 `TERMS`：活期、3个月、6个月、1年、2年、3年、5年；任一正则没匹配上就丢弃这一期
- `boc_deposit()` 的期次链接按标题「人民币存款利率表YYYY-MM-DD」取日期，结果按日期倒序；一期都没抓到时抛错（沿用旧数据）

**调息检测**（`main()`）
- 新抓到的最新一期日期 ≠ 上一份 `deposit_history[0].date` 时，写 `rate_change = { date: 新日期, detected: 当前时间 }`
- 前端在 `detected` 之后 30 天内显示顶部「调息提醒」，并给出三年期旧利率 → 新利率

**储蓄国债解析**（`parse_bond()`）
- 年份取标题里的「XXXX年」；品种：标题含「凭证式」为凭证式，否则电子式
- 发售时间正则「（将）于 YYYY年M月D日至（YYYY年）M月D日」，跨年时取第二个年份
- 每期：「第X期 … 期限X年，票面年利率为X%」，期数、期限支持中文数字（`cn_num()`，如「十一」→ 11）；一期都没解析到则跳过该公告
- 正文取「尊敬的客户 … 特此公告」，压缩空白后截前 800 字，供详情抽屉展示；旧数据里没有 `text` 的公告会重新请求一次
- 合并：以公告 URL 为键，新结果覆盖旧结果，旧的保留（列表只翻 4 页），按 `start` 倒序

**大额存单解析**（`parse_cd()`）
- 只取「常规产品」之后、遇到「X号产品」或「注：」之前的一段（找不到结束标记时取 600 字）
- 匹配「N个月 / N年期 + 利率%」，「年期」统一改成「年」
- 起存金额：表格里第一个期限后的数字（单位万元）或「N 万元起」，× 10000；都没有时默认 200000

**LPR**（`lpr()`）：查询区间 = 今天往前 330 天；按 `showDateCN` 与旧数据合并（新覆盖旧），按日期倒序，历史不断累积。

**新闻去重**（`news()`）
- 标题末尾的「 - 来源名」去掉；`pubDate` 解析失败的条目丢弃，时间统一转 UTC ISO
- 主题按查询词归类：含「国债」→ 国债，含「大额」→ 大额存单，其余 → 存款
- 按时间倒序，标题去掉非文字字符后取前 18 个字作为去重键，保留最新一条，最多 40 条

**来源状态**（`run()`）：成功记 `ok: true` 和本次时间；失败记 `ok: false`、错误信息前 120 字，`updated` 沿用上次成功时间，数据沿用上一份 `data.json`。中行利率表、国债公告两项额外记 `count`。

**前端计算**
- 利息计算器（`channels()`）：单利，`金额 × 年利率 / 100 × 年数`；大额存单金额低于 `cd.min_amount` 置灰；储蓄国债只有 3 / 5 年期，其余年限置灰；股份行 / 城商行取 `others.groups[].rates`
- 国债利率（`bondRates()`）：按 `bonds` 顺序（最新在前）取每个期限第一次出现的利率
- 下期国债（`nextBond()`）：正在发售的优先 → 已公告未开售的最近一期 → 都没有时按「3–11 月每月 10 日」推算（当天已过 10 日推到下月，12–2 月推到次年 3 月 10 日），标「预计」
- 农行核对：中行与农行 1 年 / 3 年 / 5 年利率完全一致时右侧显示「一致」，否则「不一致」

## 前端

**详情抽屉 + 列表页（通用组件 kit）**

列表页是新开的一层：从右侧滑入盖在首页上，返回时滑走；首页一直在底下不动，滚动位置不变。在列表里点开的详情盖在这一层之上；直接打开列表链接时不播进场动画；安卓手机可从左边缘右滑返回（iOS 用系统自带手势）。
- 电脑端从右侧滑出，手机端从底部升起；`Esc` 或浏览器返回关闭
- 地址写进 hash：`#/item/<类型>/<id>`、`#/list/<key>`，分享链接可直接打开对应详情或列表
- 打开的条目在当前数据里找不到（已下榜 / 过期 / 旧链接）时，弹出「这条内容已不在当前数据里」提示，并给「回到首页」按钮

本项目的条目类型（`KIT.item`）：

| 类型 | id | 内容 |
|---|---|---|
| `rate` | `deposit_history` 下标（0 = 现行） | 某次调息的各期限利率、与上次对比、前后几次调整、中行原文 |
| `bond` | `bonds` 下标 | 储蓄国债要点（发售时间、付息方式、每人限额、提前兑取）、公告原文、同品种往期 |
| `next` | 固定 0 | 下期国债预计开售日（无公告时）、购买方式、最近几期 |
| `cd` | 固定 0 | 大额存单各期限利率及比大行定期多出多少 |
| `lpr` | 固定 0 | 近几个月 LPR 1 年 / 5 年期及变化 |
| `group` | `others.groups` 下标 | 股份行 / 城商行参考利率、区间、来源文章 |
| `news` | `news` 下标 | 新闻来源、主题、同主题动态、阅读原文 |

列表页 key（`KIT.list`）：

| key | 内容 |
|---|---|
| `news` | 最新动态，支持 `?topic=国债 / 存款 / 大额存单` 筛选，每页 30 条，可加载更多 |
| `history` | 调息记录全表（执行日、活期、1 / 3 / 5 年、三年期变化） |
| `bonds` | 储蓄国债全部期次 |

**项目特有功能**
- 顶部要点卡片、利息计算器、利率对比表（每行最高值高亮）、调息阶梯折线图（悬停看利率）、国债倒计时，计算规则见「数据处理规则 · 前端计算」
- 金额、存期、主题（深色 / 浅色）保存在本机 `localStorage`（键前缀 `sv:`：`sv:amount`、`sv:term`、`sv:theme`），不上传

## 自动更新机制

| 触发方式 | 时机 |
|---------|------|
| GitHub Actions 定时任务 | 每天 09:05、17:05 北京时间（cron `5 1,9 * * *`，UTC 01:05 / 09:05；国债公告、调息一般白天发布） |
| push 到 main 分支 | 仅当改动 `scraper.py`、`others.json`、`.github/workflows/scrape.yml` 时触发 |
| GitHub Actions 手动 dispatch | 按需触发 |

- 并发组 `scrape`，不取消正在运行的任务；提交前 `git pull --rebase` 再 push
- **心跳**：`data.json` 的 `updated` 字段每次运行都变，所以每次运行都会产生一次 `data: update YYYY-MM-DD HH:MM` 提交，仓库保持活跃
- GitHub 规定公开仓库 60 天无提交会自动停用定时任务；正常情况下心跳提交可避免，如果因连续失败等原因被停用，需到 Actions 页面重新启用
