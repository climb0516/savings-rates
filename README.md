# 🏦 存哪儿 · 存款利率与国债

> 钱存哪儿利息最高？国有大行挂牌利率、大额存单、储蓄国债、中小银行参考一页对比，附利息计算器和 15 年调息记录

**🌐 在线访问：[https://climb0516.github.io/savings-rates/](https://climb0516.github.io/savings-rates/)**

---

## 功能

- **顶部要点**：大行 3 年定期（及「已多少天未调」）、大额存单 3 年、储蓄国债 3 / 5 年、**下期国债倒计时**
- **利息计算器**：输入金额、选 1 / 2 / 3 / 5 年，对比大行定期、大额存单（不足起存金额时置灰）、储蓄国债（只有 3 / 5 年）、股份行 / 城商行参考，最高的高亮并算出比大行多拿多少
- **利率对比表**：活期到 5 年各渠道利率，每行最高值高亮
- **调息记录**：中国银行历次挂牌利率表（2010 年至今），阶梯折线图（3 年 / 1 年定期 + 储蓄国债 3 年），悬停看每次的利率；下方卡片列出每次调整幅度
- **调息提醒**：中行发布新利率表后 30 天内，页面顶部高亮提示
- **储蓄国债**：下期开售倒计时（已有公告用公告日期，否则按 3–11 月每月 10 日推算并标「预计」），历次发行一览（品种、期数、3 / 5 年利率、公告链接）
- **最新动态**：国债、存款利率、大额存单新闻，可按主题筛选
- 右侧：LPR、大行中行 / 农行交叉核对、中小银行参考区间、来源状态
- 深色 / 浅色主题，手机适配；输入的金额只保存在本机浏览器

数据仅供参考，不构成理财建议。

## 数据来源

| 数据 | 来源 | 方式 |
|---|---|---|
| 大行挂牌利率 + 历次调息 | [中国银行 · 人民币存款利率表](https://www.boc.cn/fimarkets/lilv/fd31/) | 自动：列表页 → 每期页面，已抓过的期不重复请求 |
| 交叉核对 | [农业银行 · 人民币存款利率](https://www.abchina.com/cn/PersonalServices/Quotation/bwbll/) | 自动 |
| 储蓄国债各期 | [中国银行 · 公告信息](https://www.boc.cn/pbservice/bi2/)里的「储蓄国债（凭证式 / 电子式）销售公告」 | 自动：解析发售日期、期数、期限、票面利率 |
| 大额存单 | 同上，「个人大额存单」发售公告的常规产品 | 自动 |
| LPR | [中国外汇交易中心](https://www.chinamoney.com.cn/chinese/bklpr/) | 自动，每次只请求一次（限流严格，查询区间不能超过约一年） |
| 新闻 | Google News RSS | 自动 |
| 股份行 / 城商行参考 | 第三方文章整理 | **人工维护** `others.json` |

**限制**：
- 工行、建行、邮储页面是 JS 渲染，招行拦截爬虫，未接入；六大行挂牌利率一致，用中行代表、农行核对
- 中行国债公告没有发行额度，页面不显示额度
- 股份行 / 城商行没有可靠的结构化来源，活动价通常有新客 / 新资金 / 起存金额条件，只作参考，需要定期手动更新 `others.json`（改完 push 会自动重新抓取）

## 技术架构

```
GitHub Actions（每天北京时间 09:05、17:05 / 手动 / 修改爬虫或 others.json 后 push）
  ↓ python scraper.py（只用标准库）
  ↓ 中行利率表 + 农行利率页 + 中行国债 / 大额存单公告 + LPR + 新闻
  ↓ 与上一份 data.json 合并（历史期次缓存，不重复请求）
  ↓ 写入 data.json 并 commit（updated 每次都变 = 心跳，防止定时任务 60 天不活跃被停用）
       ↓
GitHub Pages（index.html 读取 data.json，计算器、图表在前端完成）
```
